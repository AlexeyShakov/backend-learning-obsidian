# Slice и append

## Задача

Дан следующий Go-код.

Необходимо определить:
- что выведет программа;
- почему программа ведёт себя именно так;
- изменится ли исходный slice `s`;
- как изменить код так, чтобы операция с `low` не изменяла элементы исходного `s`.

## Исходный код

```go
package main

import "fmt"

func main() {
	s := []int{1, 2, 3, 4}

	low := s[:2]
	low = append(low, 99)

	fmt.Println(s)
	fmt.Println(low)
}
```

## Вопросы

1. Что выведет `fmt.Println(s)`?
2. Что выведет `fmt.Println(low)`?
3. Почему `append` приводит именно к такому результату?
