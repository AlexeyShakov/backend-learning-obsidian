
## Задача

Дан общий счётчик.
Программа запускает **100 goroutines**, каждая из которых увеличивает значение счётчика **1000 раз**.
Ожидаемое итоговое значение:

```text
100000
```

Однако программа может получать значение меньше ожидаемого.

Необходимо:

- объяснить причину некорректного результата;
- исправить реализацию счётчика;
- обеспечить корректную работу при одновременном обращении из нескольких goroutines.

Вопросы:
- Какие способы исправления этой проблемы вы можете предложить?
- Реализуйте один из вариантов.
- Какие преимущества и недостатки есть у предложенных вариантов?
## Исходный код

```go
package main

import (
	"fmt"
	"sync"
)

type Counter struct {
	value int
}

func (c *Counter) Inc() {
	c.value++
}

func main() {
	counter := Counter{}

	var wg sync.WaitGroup

	for i := 0; i < 100; i++ {
		wg.Add(1)

		go func() {
			defer wg.Done()

			for j := 0; j < 1000; j++ {
				counter.Inc()
			}
		}()
	}

	wg.Wait()

	fmt.Println(counter.value)
}
```

## Ожидаемый результат

После завершения всех goroutines значение счётчика должно быть:

```text
100000
```
