
## Задача

Дано приложение, которое выполняет два независимых HTTP-запроса последовательно.

Необходимо изменить программу так, чтобы HTTP-запросы выполнялись параллельно.

Если один из запросов завершается с ошибкой, необходимо прекратить выполнение остальных запросов и вернуть ошибку.

## Требования

- HTTP-запросы должны выполняться параллельно.
- Необходимо дождаться завершения всех запросов при успешном выполнении.
- Если один из запросов завершился с ошибкой, остальные выполняющиеся запросы должны быть отменены.
- Программа не должна завершиться, пока необходимые goroutines продолжают выполняться.

## Исходный код

```go
package main

import (
	"net/http"
)

func main() {
	_, _ = http.Get("https://google.com")

	_, _ = http.Get("https://dzen.ru/")
}
```
