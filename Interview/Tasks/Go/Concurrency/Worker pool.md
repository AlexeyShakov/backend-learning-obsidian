
## Задача

Необходимо обработать поток заданий с помощью фиксированного количества воркеров.
Каждое задание представляет собой целое число. В результате обработки число необходимо умножить на `2`.
Реализовать worker pool из **3 воркеров**, который:
- получает задания из канала `jobs`;
- обрабатывает задания параллельно;
- записывает результаты в канал `results`;
- корректно завершает работу после обработки всех заданий;
- позволяет прочитать все полученные результаты.

## Ожидаемый результат

Должны быть обработаны все числа от `1` до `9`.

Для каждого задания в `results` должно попасть значение:

```text
result = job * 2
```
