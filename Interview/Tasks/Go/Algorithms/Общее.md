# Максимальное расстояние до ближайшего зрителя

## Задача

Места в кинотеатре расположены в один ряд. Только что пришедший зритель хочет сесть максимально далеко от остальных зрителей в ряду. То есть расстояние от выбранного места до ближайшего к нему зрителя должно быть максимально. Гарантируется, что в ряду всегда есть свободные места и уже сидит хотя бы один зритель. Дан ряд мест в виде массива:
- `0` — место свободно;
- `1` — место занято.
Необходимо вернуть расстояние от выбранного места до ближайшего зрителя.

## Примеры

### Пример 1

```text
Input:  [1, 0, 0, 0, 1]
Output: 2
```

### Пример 2

```text
Input:  [1, 0, 1, 0, 0, 1, 0, 0, 0, 1]
Output: 2
```

### Пример 3

```text
Input:  [1, 0, 1, 0]
Output: 1
```
